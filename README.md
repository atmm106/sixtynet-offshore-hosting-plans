## 免备案免的到底是什么

实名认证解决的是“你是谁”，ICP 备案解决的是“这个网站能不能在中国境内公开提供访问服务”，两条平行的规则线，没有因果关系。免备案的根源在于机房物理位置在境外，不是因为你买的时候没交身份证。反过来说，境外服务商照样可能要求身份核验，只是这不影响它的节点免备案。

三种组合值得记一下：

- 境外服务器做公开网站：通常既不用实名，也不用备案，付款就能开。
- 国内服务器做公开网站：既要实名，又要备案，缺一样都上不了线。
- 国内服务器做非网站业务：需要实名，但不一定需要备案。只跑内部数据库、API 接口、AI 训练、游戏后端、自动化测试，不绑域名对外渲染网页，就不涉及 ICP 备案。

备案本身的时间成本是这样：多数地区 7 到 20 个工作日，节假日顺延，涉及医疗、金融、出版这类前置审批的行业还要更久。没备案的域名如果解析到中国大陆境内的服务器，80 和 443 端口会被机房系统自动拦截打回，不是打不开就是直接拒绝连接，这一点没有商量空间。

境外节点不在 ICP 备案管理范围内，但内容仍然受机房所在地法律约束。几家做香港、美国、日本节点的服务商都在帮助文档里写了禁止违法违规内容、违者封停，这不是营销话术，是实际执行条款。

还有一个直接影响变现的点：常规的微信、支付宝支付接口大多要求提供 ICP 备案域名。如果你的站要靠这两种方式收款，免备案方案在支付环节会卡住，得走跨境版或第三方支付通道。这个限制在选服务器之前就该想清楚。

SixtyNet 官网没有公布中国大陆方向的延迟数据，第三方测评里也提到官方屏蔽了 PING，测不出值。所以 ping 不通不代表线路差，也不能拿 ping 结果当唯一判断依据。能确认的是线路类型：AS9929 是中国联通的精品网，回国走这条线通常比普通国际线路稳；第三方测评显示这家的电信方向去程和回程走 CN2，联通回程走 AS10099 加 AS9929。

作为参照，其他几家公布的延迟大致落在这些区间，具体数字受测试地区、线路和时段影响很大：

CN2 GIA 和 CN2 GT 的区别值得单独说一句：GIA 是电信 CN2 里的高端商用线路，直连国内骨干网，三网都有优化，拥堵时段相对稳；GT 是普通 CN2，繁忙时段可能绕路。同样标“CN2”，两者晚高峰表现不在一个档上，价格也差一截。

## 不写在价格里的成本

**带宽是峰值，不是保证值。** 有第三方评测做过对比，三家标称同带宽的香港 VPS，从国内访问的峰值速率分别是 12Mbps、38Mbps 和 71Mbps，差五倍多。下单前要问的是“保证带宽多少”，而不是宣传页上的那个数字。

**流量配额要按业务估。** 企业展示站月流量建议 500GB 起步，电商站 1TB 起步。部分低价套餐写“无限流量”，条款里藏着合理使用限制，长期跑满会被限速到 1 到 5Mbps。

**线路质量直接体现在丢包率上。** 普通线路晚高峰丢包率能到 3% 到 5%，页面加载要等 5 到 8 秒；优化线路可以压到 0.5% 以下。便宜的差价基本都省在这里。

**住宅 IP 有硬性使用边界。** SixtyNet 的 Residential 和 IRVINE-PRO 两条线都是住宅 IP，前者明写不开 80/443，后者默认拒绝外部扫描、只允许白名单或端口转发设备接入。买之前先想清楚你要的是建站还是别的用途。

**IP 更换和系统授权是另外的钱。** 不少服务商对最低配换 IP 收费，比如搬瓦工换一次 $8.79；恒创的 1核1G、1核2G 换 IP 也收费，除非 IP 本身故障。Windows Server 普遍要额外买授权，而且官方一般建议 2 核 2G 以上才装，1G 内存跑 Windows 会卡。

**原生 IP 可能要加价。** 恒创的日本节点默认开的是非原生 IP，配置器里写明原生 IP 需联系客服额外付费 200 元/月/个；香港和美国默认就是当地原生。做日本本地业务的人下单前必须确认这一项。

**注册环节有风控。** 有社区测评提到，SixtyNet 注册需要非中国大陆手机号接码，这一步过不了就下不了单。搬瓦工则是注册和付款时 IP 与填写国家不符会被判欺诈自动退款，需要关掉代理再操作。
